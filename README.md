# Python Todo List v0.2

这是一个适合 Python 初学者练习的命令行 Todo List 项目。

## 项目功能

v0.2 包含以下功能：

1. 添加任务
2. 查看所有任务
3. 退出程序
4. 自动保存和恢复任务

添加任务后，程序会立即把任务保存到本地的 `tasks.txt` 文件中。重新启动程序时，之前保存的任务会被自动读取。

## 文件结构

```text
.
├── main.py       # Todo List 程序代码
├── README.md     # 项目介绍和运行说明
├── .gitignore    # Git 不需要跟踪的文件
└── tasks.txt     # 保存任务，第一次添加任务时自动创建
```

## 运行方法

1. 确保电脑已经安装 Python 3。
2. 在命令行中进入项目目录。
3. 运行下面的命令：

```bash
python main.py
```

如果系统中的 Python 3 命令是 `python3`，则运行：

```bash
python3 main.py
```

程序启动后，输入菜单中的数字 `1`、`2` 或 `3`，再按回车键。

## 任务如何保存

程序使用普通文本文件 `tasks.txt` 保存任务，每个任务占一行。不需要手动创建这个文件；如果它不存在，程序仍然可以正常启动，并会在第一次添加任务时自动创建它。
