# Python Todo List v0.1

这是一个适合 Python 初学者练习的命令行 Todo List 项目。

## 项目功能

v0.1 只包含以下功能：

1. 添加任务
2. 查看所有任务
3. 退出程序

任务保存在程序运行时的内存中。退出程序后，任务不会被保留。

## 文件结构

```text
.
├── main.py       # Todo List 程序代码
├── README.md     # 项目介绍和运行说明
└── .gitignore    # Git 不需要跟踪的 Python 临时文件
```

## 运行方法

1. 确保电脑已经安装 Python 3。
2. 在命令行中进入项目目录。
3. 运行下面的命令：

```bash
python main.py
```

如果系统中的 Python 3 命令是 `python3`，则运行：

```bash
python3 main.py
```

程序启动后，输入菜单中的数字 `1`、`2` 或 `3`，再按回车键。
